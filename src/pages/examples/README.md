# `src/pages/examples/` — Layouts detail guides

This directory owns the standalone Examples > Layouts information architecture. The landing page explains the area; each routed detail page explains one complete page-shell pattern and links to its focused interactive demo.

## Routes

- `/examples/layouts` — Layouts landing page
- `/examples/layouts/header-only`
- `/examples/layouts/secondary`
- `/examples/layouts/sidebar`
- `/examples/layouts/full`

The interactive previews remain under `/layouts/*` so the detail guides and the demos have distinct jobs: guidance belongs in this directory; the demo pages let people inspect and resize the shell with minimal distraction.
