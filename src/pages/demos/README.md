# `src/pages/demos/` — demo-only helpers

These files are small compositions used to make layout and component guide pages understandable:

- `demo-card.tsx` shows a realistic card composition.
- `split-pane-demo.tsx` shows content inside the SplitPane layout primitive.

They are not production components and should not be copied into an application as a component API. Copy the underlying primitive from `src/components/` and recreate the application-specific content instead.
